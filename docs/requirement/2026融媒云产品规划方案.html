01 · 战略总纲

一条主线、三个转变、两个市场

2026 年不再以"大平台整体交付"为唯一形态，而是把底座沉淀的 AI 能力，拆成可独立售卖、可快速落地、可订阅续费的智能单品与数字员工，既守住广电融媒主场，又向泛媒体（政企数字营销）拓展增量。

把策采编审发评里能自动化的部分，交给智能单品和数字员工；人只在选题拍板和终审两处介入。

—— 2026 融媒云产品价值主张

三个转变

01

从"大平台"到"单品 + 数字员工"

把整体方案拆为 20+ 可独立售卖的轻量化智能单品和 8 个内置数字员工，降低客户决策门槛，缩短交付周期，沉淀订阅续费收入。

02

从"工具割裂"到"对话框统一入口"

以 Media Cloud 对话框为 AI Native 统一入口，打通灵感、选题、写稿、素材、拆条、成片、审核、分发全链路，消除功能断点。

03

从"一次性交付"到"数据正向飞轮"

策采编审发评全链路数据沉淀，回流到选题推荐、审核阈值等具体模型与动作，支持按传播效果计费（详见第 10 章）。

媒体主场 — 广电 / 融媒

02 · 市场与需求洞察

来自一线的三大真实痛点 + 商机三盘结构

规划不来自想象。以下痛点直接来自河北台、石家庄台、黑龙江台等客户的高频反馈，商机结构来自 2026 各大区 W/A 级商机（共 93 条，媒体机构 74 条）。

痛点 1

工具割裂、短视频链路不闭环

灵感池、智能稿件、智能搬运、数字分身、依案成片、智能快编各自独立，资源与流程无法互通，操作繁琐、学习成本高、整体效率低。

来源：石家庄台、黑龙江台

痛点 2

事实核查 / 内容合规是高频刚需

日均审核 300–500 篇，现用第三方秒塔，单篇核算成本 0.3–0.5 元。客户希望对接同类合规校验接口、嵌入灵感池页面，提升平台日活。

来源：河北广播电视台

痛点 3

盯源被动、需自动化与热点预判

编辑被动追热点、人工盯源耗时。客户明确提出两款数字员工：数据采集师（自动抓取实时推送）、热点分析师（预判潜在热点，从被动追到提前判）。

来源：河北广播电视台

客户已经把"理想产品"描述清楚了

石家庄台一站式诉求：实时抓取全网舆情热点素材 → 关键词 / URL 一键采集入库 → 自动去台标去角标去水印 → AI 智能拆条生成片段 → 统一界面完成"热点选题·素材抓取·智能拆条·模板匹配·数字人播报·智能包装·精细剪辑"全流程，并支持标准化模板批量出片。这正是 2026 轻量化智能单品 + 数字员工要交付的核心闭环。

补充痛点清单（黑龙江台 / 多台共性）

  • 文稿层：现有模型偏传统图文文风，缺抖音 / 快手 / B站短视频专属口语化文案模板，需自动纠正语句与偏差信息。
  • 素材层：需全网空镜头素材检索，入库自动去水印、去标签、视频超分预处理。
  • 合规层：需视频内容事实核查、合规校验（可接入第三方接口）。
  • 封面层：需智能封面排版与模板推荐，替代人工反复调字号、行数、安全框。
  • 拆条层：系统自主根据原视频生成拆条大纲与创意建议，无需人工先出文稿再训练拆解。
  • 入口：产品向 Media Cloud 对话框入口 + 数字员工深度集成方向升级，优先跑通短视频全业务闭环。

03 · 现状盘点与整合战略

三类散点资产，如何收敛成一个体系

2026 的真问题不是"再造新产品"，而是把已有的三类形态各异的资产——早期重平台、新数字员工、新单点工具——收敛成一套可分可合的体系，既消除客户抱怨的"工具割裂"，又能按客户分层灵活售卖。

现状：我们手里有什么

资产 A · 早期重系统

数智全媒平台

覆盖策采编审发评全链路：选题策划 / 新闻舆情 / 灵感池 / 稿件管理 / 智能媒资 / 生产工具 / 发布运营 / APP·网站终端 / 数据传播分析 / 绩效管理。

形态：整装、紧耦合、to-G 大平台 · 链路完整但偏重

资产 B · 新智能体

数字员工

以智能体（Agent）形态独立开发的新产品，把能力组织成"会干活的角色"，可按岗位订阅、对话式调用。

形态：轻、AI 原生、可独立落地

资产 C · 新单点工具

视频画布工具 · 视频生成工具

单独新开发的创作类工具：画布式多 Agent 编排非编、AIGC 视频生成，是短视频量产的核心引擎。

形态：轻、单点、当前游离于平台之外

整合不到位会怎样？

三类资产如果各走各的，正好复现客户最痛的那句话——"灵感池、智能稿件、智能搬运、数字分身、依案成片、智能快编相互独立，资源与流程无法互通"。重平台卖不动小客户，新工具又难单独支撑大单，数字员工拿不到平台的资产与上下文就成了"空壳"。所以整合的本质，是让三者共享同一套数据、能力与入口。

整合战略：一个底座 · 一个入口 · 三种售卖形态

不是把平台推倒重做，而是把它解耦下沉——重的部分沉为底座与能力中台，轻的部分（单品、数字员工、新工具）浮到上层，用统一入口把它们重新串成闭环。一句话：平台变底座，模块变能力，能力变单品，单品组成数字员工，对话框统一入口。

黏合剂一 · 内容智能底座（数据 / 知识 / 模型唯一真源）

把"智能媒资"升级为全平台唯一的资产·知识·模型底座，所有模块、新工具、数字员工都从这里取数取知识——这是消除"资源流程不互通"的根本。

黏合剂二 · Media Cloud 对话框 + 数字员工编排层

一个 AI Native 入口，把散落的工具用"对话 + 数字员工"重新编排成场景闭环；新工具（画布 / 生成）作为可被调用的创作能力（skill）接入，而非又一个孤岛。

整合五步路径（怎么落地）

第 1 步 · 数据知识统一

智能媒资 → 内容智能底座

资产、标签、知识图谱、模型收敛为唯一真源，平台各模块与新工具/数字员工共用，不再各建一套。

第 2 步 · 能力服务化

策采编审发评模块 → 原子能力 API

把选题、舆情、稿件、审核、发布等模块能力 API 化、原子化，对外提供统一能力，避免新工具与数字员工重复造轮子。

第 3 步 · 工具能力化

视频画布 / 视频生成 → 创作类 skill

新单点工具封装为可被对话框与"节目创作师"数字员工调用的创作能力，既能单卖、又能被编排进闭环。

第 4 步 · 编排成角色

能力 + skill → 数字员工 · 对话框入口

用数字员工把底层能力与单品编排成"会干活的角色"，统一在 Media Cloud 对话框与 APP/网站终端中触发。

第 5 步 · 数据回流

使用数据 → 沉淀回底座（飞轮）

策采编审发评全链路使用数据回流底座，落到选题推荐、审核阈值、拆条优选等具体模型与动作（详见第 10 章）。

04 · 产品总架构与整合路径

整合后的目标形态：一个内核、两条应用线、一台飞轮

底座沉淀资产与知识，应用线把能力拆成"智能单品 + 数字员工"对外售卖，企业数字营销底座把同一套能力镜像到政企，数据飞轮把使用数据回流到具体模型与动作。

图 4-1 · 2026 融媒云产品总架构：一个内核（L0–L1 底座）· 两条应用线（L2 单品 / L3 数字员工）· 一个统一入口 · 一台数据飞轮 · 一条第二曲线
入口

Media Cloud 对话框 · AI Native 统一入口

一句话驱动多智能体协同，消除多系统切换与功能断点，是所有单品与数字员工的统一交互层。

L3

数字员工智能体应用 + 大端大号传播矩阵

以场景为单位封装的数字员工，多 Agent 协同自动产线；传播矩阵把内容铺到微信 / 微博 / 抖音等互联网渠道与自有大端大号。

L2

轻量化智能单品（互联网生产运营场景）

灵感池、热点二创、智能拆条、一键成片、短视频稿件、数字人播报、竞品雷达、画布非编、节赛会展自动化——以「数智全媒产品平台」（框架 / CMS / 老媒资 / APP 工厂 / 发布运营）为现有系统底座，封装成可独立售卖的工具集。

L1

媒体智能内容底座（内核）

多模态汇聚 → 智能处理 → 多视角标注 → 媒体资产知识工程 → 资产价值化输出，让沉睡资产变成可理解、可调用的智能资产。

L0

传媒大模型 · 智能基座

FASM 融合大模型 + 风格模型 + 专家模型 + 多租户 + 智能体引擎 + 人机协同，为生产提供贴合本机构风格、听得懂媒体语义的模型支撑。

横切 · 企业数字营销底座

把 L1–L3 能力镜像到政企：内容采集（含创意工具 / 执法记录仪对接）、品牌调性处理、企微钉飞协作、多平台分发、数字营销百宝箱，向泛媒体市场拓展。

贯穿 · 数据驱动正向飞轮

策采编审发评全链路数据沉淀 → 选题推荐自驱动、审核阈值自决策 → 模型自进化。标杆：北京台热点选题宣发闭环、优质内容海外二创闭环。

05 · 媒体智能内容底座（内核）

把分散资产做成可检索、可调用的内容真源

正如 AI 基座为应用提供模型与数据支撑，内容底座为媒体智能化提供"资产 → 知识"支撑。它是所有智能单品与数字员工的数据与知识根基。
代表案例：北京台统一内容库、河北台统一内容库、湖北长江云、宁夏黄河云、福建海峡云。

底座怎么规划：按"汇聚 → 处理 → 标注 → 知识 → 价值 → 模型"六层递进，让资源从"能存"逐步升级为"可理解、可调用、可变现"，并向上为所有智能单品与数字员工提供统一的数据、知识与模型支撑。下表每个模块均给出能力定位、案例亮点与对应的场景·痛点·单品。

①

多模态汇聚（多类型数据文件管理）

流矩阵汇聚多品牌多协议兼容统一内容库
定位

底座的"资源入口"。视频 / 图片 / 音频 / 文档统一上传存储，多品牌多协议兼容。

阐述

很多台多年积累的录播、文稿散落在不同平台、格式各异、难以查找，成了"沉睡资产"。统一接入各类内容流，解决多品牌多协议兼容问题，把离散资源汇成单一内容库真源。

案例成果 / 业务亮点
  • 电视台统一内容库：北京电视台统一内容库、河北电视台统一内容库
  • 省级融媒平台：湖北长江云、宁夏黄河云、福建海峡云
举例

某台原本素材分散在录播、采编、网盘多套系统，汇聚入库后形成全台唯一内容真源，后续标注、检索、生产都基于它。

业务场景新建 / 整合统一内容库
解决痛点资源散落、格式各异、难检索
对应单品智能媒资 · 内容汇聚
②

多模态内容处理

解析转码清洗去重去劣画质提质
定位

资源的"预处理车间"。入库即完成解析、格式转化、清洗与提质。

阐述

对多模态内容解析、格式转化、清洗（去重去劣）、画质提质，让资源从"能存"升级为"能用"，从"文件名可见"升级为"内容可理解"。

案例成果 / 业务亮点
  • 视音频转码、媒体处理调度模块、媒体处理监控模块
  • 视频超分提质，老素材重新可用于新媒体二创
举例

历史标清素材经自动超分提质后达到新媒体可用画质，沉睡老素材重新进入生产链路。

业务场景素材入库 / 老素材活化
解决痛点格式杂、画质差、不可直接用
对应单品转码提质 / 媒体处理调度
③

多视角媒体资产标注

AI 多维理解人机协同标注人脸·OCR·ASR·场景·物体
定位

让内容"可理解"的标注中枢。

阐述

由理解内容的智能体先通过 ASR、图像识别、语言模型把视频完整文本化、情景化；专业标注智能体再按不同行业、不同栏目的上百个维度自动精细标注，并自动关联相关内容。

案例成果 / 业务亮点
  • 提供人脸识别、OCR 文字识别、ASR 语音识别、场景分析、物体检测等自动处理
  • "理解内容 → 专业标注"双智能体协同，机器"看懂"视频的内容、结构与价值
举例

一段新闻视频入库后自动生成结构化文本与上百维标签，编辑无需逐帧看片即可定位所需片段。

业务场景内容理解 / 检索准备
解决痛点标注靠人工、效率低、维度浅
对应单品智能标签服务

数字员工（买一个岗位的活儿）

对应黏合剂二。数字员工执行平台 + 内置场景 + 定制场景，把一个岗位的生产场景自动干掉。原"场景套件"并入此处。

高频刚需、要自动化

河北台合规、石家庄短视频量产

三种形态是"升降通道"，不是三套产品

客户可从一个单品或一个数字员工低门槛进入，用顺手了再加购、再上平台；平台客户也能反向加购单品与员工。底座同源、能力同源，升级即开通、不重复实施。

09 · 企业数字营销底座（泛媒体拓展）

把媒体内容能力，镜像成企业的"数字营销车间"

事业部向泛媒体业务市场拓展的主方向。同一套"资产 → 知识 → AIGC → 分发"能力，换一组业务语义，即可服务品牌市场部、政府宣传、连锁与出海企业。
代表案例：双胞胎集团企业内容管理平台、极兔快递创意内容库。

数字营销基座

  • 智能采集：通用内容 + 创意内容（Adobe / Figma 深度集成）+ 特殊内容（执法记录仪 / 监控 / 采编系统对接）
  • 智能处理：理解品牌调性与内容风格，自动评估素材与品牌规范一致性
  • 智能标注 + 检索：标签层 + 知识层，意图检索、按营销主题自动汇聚资料包
  • 协作管理：权限 / 版本 / 审批，集成企业微信、钉钉、飞书
  • 价值应用：一键分发微信 / 微博 / 抖音 / 小红书，对接 CRM / CDP / 电商；企业知识库 AI 问答；可交易数字资产

AIGC 数字营销中心

  • 策略营销引擎：定义数字员工（热点发现 / 营销对标 / 内容编辑 / 发布推广 / 数据分析），自动产线
  • AI 竞品雷达：企业舆情、竞品情报、同选题对标、写作灵感
  • AI 灵感写作：热点报题、角度推荐、企业风格写稿
  • 数字营销百宝箱：AI 轻工具（剪辑 / 格式转换 / 尺寸适配 / 水印 / GIF / 海报 / 文生图视频）、出海工具（多语言字幕 / 海外电商风格视频）、数字人（播客 / 虚拟直播带货）、创意工具、传播效能评估

为什么企业要买？

AI 赋能企业数字化营销全场景：员工培训、品宣管理、对外宣发 / 推广、在线引流、在线交易——直接指向"为企业创收"。极兔快递用创意内容库实现全球分支机构市场宣发材料的统一收集与统一下发；双胞胎集团实现总部与数百家分厂宣传 / 培训资料的汇聚与管理。这是把"内容成本中心"转为"营销增长引擎"。

10 · 数据驱动正向飞轮

回流数据 → 改进的具体动作 → 落地价值

飞轮不讲虚的：把每个生产环节产生的数据，落到它具体改进了哪个模型 / 动作、带来什么可衡量结果。下表是五条可落地的数据闭环，北京台两个标杆场景是其中的完整实例。

感知热点 → 选题决策 → 内容生产 → 多端分发 → 监测评价 → 数据回流

回流数据改进的具体动作落地价值
稿件 / 视频实际传播效果（打开、完播、互动）灵感池选题推荐：实际跑出来的角度 / 题材，下次优先推选题命中率↑，减少无效选题
人工复核中被推翻的审核样本合规模型阈值与规则校准漏报 / 误报↓，人工复核量↓
拆条片段的采用 / 弃用记录拆条大纲与片段优选模型成片采用率↑，返工↓
一稿多发各平台版本的表现各平台 / 账号调性适配模型适配版本表现↑，少靠人改版
海外各渠道互动数据反哺国内选题池的高潜话题海外二创选题更准

两个完整实例（北京台）

标杆场景一

热点选题宣发闭环

全网热点感知→ 策略 Agent 推送舆情包→ 选题会一键决策→ 历史素材辅助→ 稿件生产→ 传播评价→ 反哺推送策略

目标用户：编导（核心）、值班编辑（协同）、台领导（管理）。

预期效果：打通舆情数据与选题决策的数据断点，让数据中台的舆情资产真正转化为编导生产力；通过历史素材复用与竞品角度参考，避免"千稿一面"。

标杆场景二

优质内容海外二创闭环

成品稿件智能分析→ 账号调性匹配→ 多渠道适配版本→ 一键分发→ 传播监测→ 用户互动回流选题池

目标用户：国际传播团队（核心）、国内新闻中心（协同）。

预期效果：构建"国内生产、海外适配"新范式，建立跨文化智能适配能力，打通"海外反馈—国内策源"双向循环，持续挖掘全球传播潜力选题。

11 · 2026 路线图与优先级

结合商机迫切度的四季度节奏

以"先跑通标杆闭环、再规模化复制"为原则，优先满足河北 / 石家庄 / 黑龙江台已明确的短视频闭环与合规刚需，再扩展到 AIGC 工具平台与政企数字营销。

Q1 · 已启动（夯实）

产品清单定稿 + 短视频闭环 MVP + 综合合规审核员

泛媒体售卖产品清单 V1.0 定稿与限价；在石家庄台、黑龙江台跑通短视频量产员工（热点搬运 / 新闻拆条）MVP；为河北台上线综合合规审核员（接第三方接口、嵌入灵感池）。

Q2 · 商品化

数字员工执行平台 + 内置员工上架 + 单品 SKU 化

上线数字员工执行平台与对话框入口；选题哨兵、短视频量产系列、综合合规审核员等内置员工上架（按内置场景收费）；轻量化单品完成 SKU 化与定价。

Q3 · 规模化

AIGC 工具平台规模复制 + 定制员工 + 数据闭环

把工具集打包为 AIGC 工具平台，规模化交付陕西广电、天府融媒、北京台稿件库三期、爱上电视；开放频道 / 渠道维度的定制员工（订阅场景）；落地北京台两个数据闭环实例。

Q4 · 拓展

企业数字营销底座产品化 + 政企拓展

以极兔 / 双胞胎为标杆完成企业数字营销底座产品化，向政企（华北油田、网信办、电信等）拓展；跑通五条数据回流闭环，沉淀效果付费模式。

落地抓手

产品收敛为三层：内容智能底座（能力真源）+ 智能单品（按环节卖能力）+ 数字员工（按场景卖自动化的活儿）；售卖收敛为三种形态，按客户处境匹配。先在河北 / 石家庄 / 黑龙江台跑通合规与短视频量产，再规模复制到 AIGC 工具平台与政企数字营销。
