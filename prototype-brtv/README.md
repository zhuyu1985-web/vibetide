# 北京广播电视台 · 智能交互工作台 — 三端原型

基于 VibeTide「智能交互工作台」逻辑，为 **北京广播电视台（BRTV）** 设计的高保真交互原型。
红白主基调（**故宫宫墙红 + 汉白玉白 + 铜金点缀**，BRTV 红底白字台标基因），炫酷大气、全程动效。

> 演示主线：**「北京迎入冬来最强寒潮 · 多部门启动应急响应」** —— 一条选题从热点研判到多平台分发的完整智能生产闭环。

---

## 🚀 如何打开

**方式一（推荐 · 最稳）** 双击 `启动.command`
自动起本地服务并在浏览器打开 `http://127.0.0.1:8848/index.html`。关闭终端窗口即停止。

**方式二** 命令行
```bash
cd prototype-brtv
python3 -m http.server 8848
# 浏览器访问 http://127.0.0.1:8848/index.html
```

**方式三** 直接双击 `index.html`
多数浏览器可直接打开（已本地化 React/Babel，完全离线）。个别 Chrome 版本会限制 `file://` 下 iframe 加载本地文件 —— 若启动壳里画面空白，改用方式一/二，或直接双击 `pc.html` / `app.html` / `im.html` 单独查看（单页在 `file://` 下均正常）。

## 📦 打包成单文件（直接发送）

如果要把整套原型发给别人「一个文件双击就能看」，用打包脚本合成一个自包含 HTML：

```bash
node prototype-brtv/build-single.cjs
# 产出 → prototype-brtv/BRTV-智能交互工作台-单文件.html （约 1.2 MB）
```

- 把 5 个工作台 + 共享 CSS / 数据 / 图标 / React 运行时**全部内联**到一个文件
- JSX 在打包时**预编译**成普通 JS（运行时不需要 2.8MB 的 Babel，体积更小）
- 每个工作台以 `iframe srcdoc` 内联，切换器无缝切换
- **零外部依赖**：直接把这一个 `.html` 发给对方，双击即可在浏览器看全部效果（含 `file://`，无需服务器）

> 改了任何源文件（`*.html` / `assets/*`）后，重新跑一次 `build-single.cjs` 即可刷新单文件。

| 场景 | 优先级 | 形态 | 一句话定位 |
|---|---|---|---|
| **智能生产** | P0 | 完整深度流程 | 门户心脏 · AI 完成 80% 粗活，人工 20% 精修终审 |
| 智能审核 | P0 | 概览页 | 安全红线守护者 · AI 预筛标记，人工终审不可跳过 |
| 融媒直播 | P1 | 概览页 | 直播全流程自动化 · AI 搭建推流拆条，导播人工干预 |

| 传播反馈 | P1 | 概览页（深色大屏） | 全平台数据自动采集分析 · 反哺选题形成大闭环 |
| 用户运营 | P1 | 概览页 | 千人千面推荐 + AI 互动 · 人工专注策略设定 |

### 智能生产 · 7 步闭环（PC 端深度演示，每步输出物可再次编辑）
素材入库 → AI 自动打标 → 跨模态检索 → **AI 粗剪/撰稿** → 多版本一键分产 → 人工精修终审 → 一键分发

- **稿件**：AI 初稿，contentEditable 直接改字 + 改写/润色/扩写
- **视频**：粗剪播放器 + 分镜时间轴 + 视频/音频/字幕三轨
- **多版本**：一键分产电视长版 / 客户端竖屏 / 听听FM音频版 / 国际传播多语种
- **图片**：题图可换图重生成（骨架屏动效）
- **音频**：波形播放器
- **分发**：多平台勾选 + 发布成功动效

## 🎨 设计说明
- **配色**：白底为主（汉白玉暖白 `#FBF8F4`）+ 宫墙红体系（主红 `#C8132A` / 深红宫墙 `#87271F` / 铜金 `#C19A52`，已微调更沉稳、更暖、弱霓虹）；传播反馈用深色大屏点缀，冷热对比。
- **图标**：全站统一线性 SVG 图标库（`brtv-icons.js`，~55 个，currentColor 描边），不用 emoji，专业克制。
- **字体**：系统中文字体栈（PingFang / 思源 / 宋体），衬线显示字更挺括、CJK 字距微调，不依赖外网字体。
- **动效**：数字滚动、流水线节点点亮、卡片 hover 升起、AI 生成骨架屏、淡入位移、红色扫描线、端切换淡入。
- **数据**：均为贴合北京台业务的拟真 mock 数据；图片用「色块 + 图标」表达内容（规避版权），非真实新闻画面。
