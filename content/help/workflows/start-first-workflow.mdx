本页带你**从零启动一个工作流**,跑完后能看到完整 mission 产出。如果你已经登录,且管理员给你的账号配了"任务启动"权限,这个流程大约花 5-10 分钟,真实跑出一篇可发布的稿件。

## 选哪个模板

新人推荐第一次跑 **"每日早报"**——它步骤少、依赖少、出错概率低,适合熟悉工作流机制。其他可选的入门模板:

- **每日早报**:小雷抓热点 → 小子改写 → 小文排版,3 步出 5 条短稿
- **热点深度追踪**:1 个热点话题做行业改写,出多版本稿件
- **选题对标**:对比 3 家友媒今天报了什么、你漏了什么

## 启动步骤

<Steps>
1. 进入 `/home` 首页,在场景网格里找到 **每日早报** 卡片
2. 点击卡片,弹出 **启动新任务** 对话框
3. 填两个必填参数:**日期窗口**(默认今天)、**TOP N 话题数**(默认 5)
4. 点 **启动**,系统创建一个 mission 并跳转到详情页
5. 在详情页 timeline 等候每一步执行,大约 30-90 秒可完成全部 3 步
6. 跑完后点 **查看产物** 跳到稿件列表,看刚刚生成的 5 条早报
</Steps>

## 关注三个细节

第一次跑完后,**强烈建议你回到 mission 详情页**仔细看三件事:

### 1. 执行 timeline

每一步显示开始 / 结束时间、执行员工、消耗 token、产出 artifact。这是排查"为什么慢""为什么失败"的第一现场。

### 2. 输入 / 输出参数

点开任意一步,左侧是该步的 **输入参数**(从上一步继承的字段),右侧是 **输出**(本步产出的字段)。理解参数流转是后续做自定义工作流的前提。

### 3. 产物落表

不同类型工作流产出物落在不同业务表:稿件 → `articles`,视频 → `media_assets`,数据报告 → `reports`。详情页底部 **产物** 区会给你跳转链接。

<Callout type="warn" title="跑失败也别慌">
新建工作流第一次跑失败是常态(网络抖动、API 限流、prompt 不稳)。点 **重试** 即可,系统会从失败的 step 继续,前面成功的步骤不会重跑。详见 <DocLink href="/help/workflows/concepts">工作流概念</DocLink>。
</Callout>

## 第二步:把它定时化

跑通一次后,可以给这个工作流挂一条 **定时任务**,让它每天早上 7 点自动启动,不用手动点。配置方法见 <DocLink href="/help/workflows/scheduling">定时任务配置</DocLink>。
