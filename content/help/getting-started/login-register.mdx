本文介绍 Vibe Media 的登录与注册流程。当前平台采用**邀请制 + 邮箱密码**的账户体系,不开放公开自助注册——这是为了保障团队边界与数据安全。

## 账户开通方式

绝大多数用户的账号是由**组织管理员**(通常是主编 / 总监)在系统管理后台为你开通的。流程如下:

<Steps>
1. 管理员进入 **系统管理 → 用户管理**
2. 点击 **邀请成员**,填写你的邮箱和角色
3. 系统生成初始密码,管理员通过私人渠道发送给你
4. 你在登录页输入邮箱 + 初始密码,即可进入平台
</Steps>

<Callout type="warn" title="首次登录后请立即改密码">
初始密码是管理员可见的、临时的——首次登录后请到 **个人设置 → 安全** 改成自己专属的密码,避免账号被冒用。
</Callout>

## 登录页

登录页路径是 `/login`,只需填邮箱 + 密码两栏即可。当前平台**只支持邮箱密码**,不支持手机号、第三方登录(微信 / 钉钉 / 飞书)、单点登录(SSO)。这是经过权衡后的设计:媒体行业对账号管理透明度要求高,不引入额外身份提供方反而更可控。

## 忘记密码怎么办

平台**没有自助找回密码**功能(没有邮件验证、没有验证码短信)。这是有意的安全选择——任何"密码重置入口"都可能被钓鱼利用。流程是:

<Steps>
1. 联系你的组织管理员
2. 管理员在 **用户管理** 找到你的账号,点 **重置密码**
3. 管理员把新密码私下交给你
4. 你登录后立即在 **个人设置** 改成新密码
</Steps>

详细审计与权限说明,请看 <DocLink href="/help/admin/users-roles">用户与角色</DocLink>。

## 会话有效期

登录会话使用**加密 cookie**,默认有效期 7 天(滑动续期)。也就是说你登录后 7 天内只要还有操作,cookie 会自动延续不会过期。超过 7 天没操作 / 主动登出 / 浏览器清缓存,会被踢回登录页。
