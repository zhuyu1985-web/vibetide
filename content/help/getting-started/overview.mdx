Vibe Media(中文名"潮汐媒体")是一个面向媒体行业的 AI 内容生产平台。和传统 CMS 不一样,它的核心不是"管文件、发文章",而是**用 8 位有人设、有专长的 AI 员工组成虚拟编辑部**,从热点发现一路协作到全渠道发布,把过去靠人力串联的内容生产链路压缩到一条可观测的工作流里。

## 我们解决什么问题

媒体团队的真痛点其实不在"写"——是**串联**:发现热点要刷十个 App、选题要在群里反复对齐、写完要审、审完要排版、排版完要分发到七八个渠道,中间还要跟踪数据回流。Vibe Media 把这些环节都装进**任务(mission)** 里,每一步都有专门的 AI 员工负责,你只看产出、做决策。

## 三个核心概念

<Callout type="tip" title="新人请重点记三件事">
1. **场景(scenario / workflow_template)**:可复用的多步任务模板,比如"每日早报""热点深度追踪"。
2. **AI 员工**:8 个常驻 + 自定义,各有职责与技能,负责执行步骤。
3. **任务(mission)**:模板的一次具体执行,产出可追溯的稿件 / 视频 / 数据报告。
</Callout>

## 一张图理解链路

```
热点发现 → 选题策划 → 素材采集 → 创作 → 审核 → 发布 → 数据回流
   小雷     小策      小子    小文+小剪 小审    小发      小数
```

每个环节都有员工专属技能(skill),系统会根据熟练度(proficiency)自动分配最合适的员工。详细员工分工见 <DocLink href="/help/ai-employees/employee-roster">8 位 AI 员工花名册</DocLink>。
