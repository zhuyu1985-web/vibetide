渠道发布是稿件离开 Vibe Media、走向公众的最后一步。本页介绍**全渠道一键分发**的工作机制、各平台的适配规则、发布前最后一道审核流程,以及发布后数据回流的链路。把这一步做扎实,后面的数据分析才有意义。

## 全渠道一键分发

进入稿件详情页,顶部右侧 **发布** 按钮会展开渠道选择面板。当前接入的平台包括:

| 渠道 | 适配内容类型 |
|---|---|
| **微信公众号** | 图文(单图 / 多图)、视频 |
| **微博** | 短文 + 9 图 / 长文 / 视频 |
| **视频号** | 视频(横版 / 竖版) |
| **抖音 / 头条** | 视频 / 微头条 |
| **小红书** | 图文 + 视频 |
| **本地 CMS(华栖云)** | 9 个 APP 栏目按需投放 |

勾选目标渠道 → 点 **发布**,系统会:
1. 调 <EmployeeBadge id="xiaofa" /> 做平台适配(标题 / 摘要 / 封面)
2. 推送到各平台开放接口
3. 回写发布凭证 + 跳转链接

## 平台适配规则

各平台对内容有自己的规则。<EmployeeBadge id="xiaofa" /> 会自动处理:

<Callout type="info" title="自动适配示例">
- **微博**:140 字摘要 + 9 图 + #话题#
- **微信公众号**:Markdown → 公众号原生编辑器格式
- **视频号**:封面 + 60 字标题 + 简介
- **小红书**:首图 + 短标题 + emoji + #话题#
</Callout>

不满意自动适配的话,可在发布对话框里 **手动覆盖**每个平台的标题 / 摘要 / 封面。

## 发布前最后审核

为了避免误发,系统在点 **发布** 后会做最后一道审核:

<Steps>
1. **合规扫描**:敏感词 / 涉政 / 涉黄 黑名单
2. **链接检测**:外链是否可访问、是否含追踪参数
3. **图片审核**:封面 / 内嵌图是否合规、清晰度是否达标
4. **版权提示**:正文 / 图片 / 视频是否标注来源
</Steps>

任一项不通过会标红,**全部 pass** 才会真正推送到平台。这一步通常 10-30 秒完成,**强烈建议保留**——已经救过很多次"差点发出去的事故"。

## 发布后数据回流

发布成功后,系统每天会**自动回流数据**:
- **阅读量 / 播放量**:每小时拉一次
- **点赞 / 评论 / 转发**:每 6 小时拉一次
- **粉丝增长**:每天一次

回流数据进入 `/analytics`,可在数据报告里做归因分析。详细字段含义见 FAQ,部分平台 API 有滞后,数据可能延迟 1-2 小时。详细的发布失败排查可看 <DocLink href="/help/faq">常见问题</DocLink>。
